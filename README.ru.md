Steam Torrent Finder — расширение для Chromium, которое добавляет кнопку **Search torrents** прямо на страницы игр в Steam. Включённые источники опрашиваются параллельно, а результаты появляются по мере ответа.

## Возможности

- 5 встроенных источников: PirateBay, 1337x, Rutracker, FreeTP и Online-Fix
- Свои источники через простой URL с `{q}` вместо поискового запроса
- Папки и отдельное включение/выключение источников
- Русский и английский интерфейс
- Фильтрация результатов и группировка версий
- Проверка magnet/URL и экранирование данных со сторонних сайтов
- Без своего сервера и аналитики — запросы идут напрямую из браузера

> Расширение ничего не хранит и не раздаёт. Оно только показывает ссылки, которые возвращают сторонние сайты.

## Встроенные источники

| Источник | Что показывает |
|---|---|
| **PirateBay** | Magnet-ссылки с переключением между зеркалами |
| **1337x** | Magnet-ссылки из поиска игр |
| **Rutracker** | Результаты для пользователей, вошедших в Rutracker |
| **FreeTP** | Страницы релизов с Online-Fix |
| **Online-Fix** | Страницы релизов с Online-Fix |

Rutracker выключен по умолчанию.

Сторонние сайты могут менять разметку, блокировать запросы или временно не работать. В таком случае источник может перестать отдавать результаты до обновления парсера.

## Свои источники

Свой источник добавляется через обычный **GET**-URL, где `{q}` стоит на месте поискового запроса.

Пример:

```text
https://example.com/search?q={q}
```

В popup:

1. Открой **Custom tracker**.
2. Вставь URL с `{q}`.
3. Нажми **Test**.
4. Сохрани источник, когда результат выглядит правильно.

Проверочный запрос выполняется без cookies и без повторных попыток. Свои источники тоже никогда не получают cookies.

Подробнее: [docs/CUSTOM_TRACKERS.md](docs/CUSTOM_TRACKERS.md)

## Установка

Пока расширение не опубликовано в Chrome Web Store.

1. Скачай или клонируй этот репозиторий.
2. Открой `chrome://extensions`.
3. Включи **Режим разработчика**.
4. Нажми **Загрузить распакованное расширение**.
5. Выбери папку, где находится `manifest.json`.
6. Открой страницу игры в Steam.
7. Нажми **Search torrents** рядом с названием игры.

Работает в Chromium-браузерах для ПК с поддержкой Manifest V3. Проект разрабатывается и тестируется в Chrome.

## Приватность и безопасность

У расширения нет аккаунтов, собственного сервера и аналитики.

- Названия, URL и magnet-ссылки проходят проверку перед отображением.
- Ссылки из своих источников ограничиваются тем же доменом.
- Cookies используются только там, где это нужно встроенному источнику с авторизацией. Свои источники cookies не получают.
- Запросы идут напрямую из браузера, поэтому расширение **не является** VPN, прокси или средством анонимности.

## Ограничения

- Сайты трекеров могут изменить HTML, начать блокировать запросы или отключиться.
- Свои источники работают с серверными GET-страницами. JavaScript-only поиск, POST-формы и CAPTCHA не поддерживаются.
- Для полного поиска в Rutracker нужно быть авторизованным в том же браузере.
- Расширение только ищет и открывает ссылки — это не менеджер загрузок.
